### 4.4 安装命令（M1-3 / M1-4 执行）

```powershell
# 1) 先 CUDA 版 torch（走官方索引，不走清华镜像）
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126

# 2) 其余依赖（走已配置的清华镜像）
pip install timm numpy scikit-learn matplotlib seaborn tqdm pyyaml pillow `
            fastapi "uvicorn[standard]" sqlalchemy pydantic pydantic-settings `
            "python-jose[cryptography]" "passlib[bcrypt]" "bcrypt==4.0.1" `
            python-multipart pytest httpx

# 3) 冻结版本（复现依据）
pip freeze > backend\requirements.txt
```

**CUDA 版 torch 下载慢的备选方案**（按顺序尝试）：

1. 官方 `cu126` 索引（首选）；
2. `--index-url https://download.pytorch.org/whl/cu124`（降一档 CUDA）；
3. 上海交大镜像 `https://mirror.sjtu.edu.cn/pytorch-wheels/cu126`（社区镜像，使用前先验证包完整性）；
4. 最后兜底：先用现有 CPU 版跑通 M1 数据管道，把 M2 训练顺延（**不推荐，会挤压总周期**）。

## 7. 中文字体与显示注意事项

- matplotlib 默认字体不含中文，绘图前需设置：`plt.rcParams['font.sans-serif'] = ['Microsoft YaHei']`、`plt.rcParams['axes.unicode_minus'] = False`，否则图中的中文会显示成方框。
- 混淆矩阵 102×102 中文类别名会重叠 → 用英文名 + 每 5 类一个刻度，或同时导出英文版与中文版。
- 前端 Element Plus 默认已是中文语系友好，但日期/分页文案需 `zh-cn` locale 配置。
