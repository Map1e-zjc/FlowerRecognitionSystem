# 02 · 技术架构与接口契约

## 1. 总体架构

```
┌─────────────────────────────────────────────────────────────────────┐
│                          浏览器 (Chrome / Edge)                      │
│   Vue3 + Vite + TS + Pinia + Element Plus + ECharts + Axios          │
│   登录/注册 │ 识别上传 │ 结果Top-5 │ 花卉百科 │ 识别历史 │ 模型对比    │

                                │ HTTP / JSON  (Authorization: Bearer JWT)
                                │ 开发: Vite 代理 → :8000
                                ▼
┌─────────────────────────────────────────────────────────────────────┐
│                      FastAPI 后端 (:8000)  uvicorn                   │
│  api/  auth · predict · flowers · history · models · stats          │

│  services/  inference(模型单例) · knowledge · metrics               │

└───────┬────────────────────────┬───────────────────────────┬────────┘
        │                        │                           │
        ▼                        ▼                           ▼
┌───────────────┐      ┌──────────────────┐        ┌──────────────────┐
│ SQLite 文件    │      │ uploads/ 图片存储 │        │ PyTorch 推理      │
│ flowers.db    │      │ {user}/{uuid}.jpg│        │ 权重 ml/outputs/  │

└───────────────┘                                  └──────────────────┘

        ┌─────────────────── 离线阶段（M1—M2，不参与运行时） ──────────────┐
        │ ml/  Flowers-102 → 数据增强 → 迁移学习训练 → 评估 → metrics.json │
        │      ResNet-50 / EfficientNet-B0 / ConvNeXt-Tiny / ViT-B/16      │
        └──────────────────────────────────────────────────────────────────┘
```

**关键运行原则**

1. **模型单例**：FastAPI `lifespan` 启动时加载一次权重到 GPU，常驻显存；请求内只做前向推理，绝不在请求里 `load_state_dict`。
2. **训练与推理解耦**：离线产出 `metrics.json` / `.pth` / `figures/*.png`，后端只读取，不参与训练。
3. **配置外置**：所有可变项（数据库 URL、JWT 密钥、密钥有效期、上传目录、模型路径、默认模型）放 `.env`，代码内不硬编码。

## 2. 技术选型表

| 层次 | 选型 | 版本策略 | 理由 |
| --- | --- | --- | --- |
| 深度学习 | PyTorch + torchvision + timm | torch ≥ 2.4 (cu12x) | 迁移学习生态最全，timm 提供丰富预训练主干 |
| 数据增强 | torchvision.transforms v2 | 随 torchvision | 无需额外依赖，够用 |
| 训练工具 | 自写 train.py + tqdm + TensorBoard(可选) | — | 轻量、可读、便于写进报告 |
| 后端框架 | FastAPI + uvicorn | FastAPI ≥ 0.110 | 自动 OpenAPI 文档，性能好，类型友好 |
| ORM | SQLAlchemy 2.x | ≥ 2.0 | 成熟，便于后续换库 |
| 校验 | Pydantic v2 + pydantic-settings | ≥ 2.5 | 请求校验与配置管理 |
| 认证 | python-jose[cryptography] + passlib[bcrypt] | — | JWT 签发/校验 + 密码哈希 |
| 数据库 | SQLite | 内置 | 单文件零运维（ADR-010） |
| 图像处理 | Pillow | ≥ 10 | EXIF 纠正、尺寸校验 |
| 前端 | Vue3 + Vite + TypeScript | Vue ≥ 3.4 | 上手快、中文生态好 |
| 状态/路由 | Pinia + Vue Router | — | 标准组合，token 与用户态管理 |
| UI 组件 | Element Plus | — | 表格/表单/上传组件开箱即用 |
| 图表 | ECharts | ≥ 5.5 | 置信度条形图、训练曲线、混淆矩阵热力图 |
| 请求 | Axios | — | 拦截器统一注入 token、统一错误提示 |

## 4. REST API 契约

统一前缀 `/api/v1`。统一响应包装：成功 `{"code":0,"message":"ok","data":{...}}`；失败 `{"code":<业务码>,"message":"中文提示","data":null}`。HTTP 状态码与业务码同时使用。

### 4.1 认证

| 方法 | 路径 | 说明 | 认证 |
| --- | --- | --- | --- |
| POST | `/api/v1/auth/register` | 注册：`{username,email,password}` → 用户信息 | 否 |
| POST | `/api/v1/auth/login` | 登录：`{username,password}` → `{access_token,token_type,expires_in,user}` | 否 |
| GET | `/api/v1/auth/me` | 当前用户信息 | 是 |

### 4.2 识别（核心）

| 方法 | 路径 | 说明 | 认证 |
| --- | --- | --- | --- |
| POST | `/api/v1/predict` | `multipart/form-data`: `file` + 可选 `model_name` → Top-5 结果 | 是 |

响应 `data` 示例：

```json
{
  "record_id": 128,
  "model_name": "vit_b16",
  "latency_ms": 186.4,
  "image_url": "/uploads/3/9f2c....jpg",
  "predictions": [
    {"class_id": 73, "name_en": "rose", "name_cn": "玫瑰", "confidence": 0.9321},
    {"class_id": 74, "name_en": "...", "name_cn": "...", "confidence": 0.0312},
    {"class_id": 12, "name_en": "...", "name_cn": "...", "confidence": 0.0091},
    {"class_id": 55, "name_en": "...", "name_cn": "...", "confidence": 0.0044},
    {"class_id": 31, "name_en": "...", "name_cn": "...", "confidence": 0.0018}

```

错误码：`4001` 文件类型不支持、`4002` 文件超过 5 MB、`4003` 图片损坏无法解码、`5001` 模型未加载、`5002` 推理失败。

## 6. 安全与工程要点

1. **上传安全**：MIME + 后缀双白名单；`Pillow.verify()` 校验可解码；文件名重命名为 `uuid4().hex`，按 `uploads/{user_id}/` 分目录，杜绝路径穿越。
2. **鉴权**：所有"我的数据"接口强制 `user_id == current_user.id`，越权返回 404（不泄露资源存在性）。
3. **密钥**：`SECRET_KEY` 由 `.env` 提供，`.env` 不入版本库，仅提交 `.env.example`。
4. **异常**：全局异常处理器把未捕获异常转成中文提示 + 日志，绝不把堆栈返回前端（NFR-04）。
5. **CORS**：开发模式允许 `http://localhost:5173`，生产模式由同源静态托管，无需放宽。
6. **日志**：请求级日志（路径、耗时、用户、结果），推理耗时写入 `latency_ms` 字段，便于报告中做性能分析。

## 7. 前后端联调约定

| 项 | 约定 |
| --- | --- |
| 端口 | 后端 `8000`，前端开发 `5173` |
| 代理 | Vite `server.proxy['/api'] → http://127.0.0.1:8000`，避免 CORS 与硬编码域名 |
| 图片访问 | 后端挂载 `/uploads` 静态目录，接口返回相对 URL |
| 时间格式 | ISO 8601 字符串，前端统一格式化 |
| 分页参数 | `page`（1-based）、`page_size`（默认 10，上限 100） |
| 错误处理 | Axios 响应拦截器统一 `ElMessage.error(message)`，401 自动清理 token 并跳登录页 |
